# Moon Koi

A giant golden koi leaps out of a tiny teacup and reaches for the moon —
one impossible leap, drawn from scratch with PIL.

The entry image is `entry.png` (1024×1024 PNG). `main.ts` copies it to
`$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`); running it
twice writes byte-identical output. `draw_image.py` is the generator that
drew the image, so the artwork is reproducible from this repository.
